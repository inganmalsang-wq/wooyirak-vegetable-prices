경락가격 현황

원/kg · 같은 시장, 세부 품종, 원래 포장규격끼리만 전일·전주·전월 비교

품목 / 품종도매시장경매 원규격kg당 경락가전일7일 전30일 전표본 건수상세
경락 데이터가 연결되면 자동으로 표시됩니다.
경락가는 실제 낙찰 거래의 원규격 가격을 kg당으로 환산한 뒤, 동일 품종·동일 규격 그룹의 중앙값으로 계산합니다. 공식 전체 평균가가 아닙니다. 품질등급은 제공 API에 없어 비교 기준에서 제외되며, 규격이 불명확한 거래도 제외됩니다.

납품단가 비교

본사·점포 납품가격과 경락 기준가격의 차이를 확인

경락가격과 납품가격을 비교하려면 먼저 실제 데이터가 필요합니다.
납품단가는 현재 브라우저에만 저장됩니다. 다른 기기에는 공유되지 않으며, 배송비·선별비·가공비·부가세 등은 별도로 검토해야 합니다.
